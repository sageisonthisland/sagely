# Sagely

This is my personal LuaTeX macro package that I use for...
everything. I abandoned LaTeX years ago.

## Installation

Copy the contents of the repository to `~/texmf/tex/`.

You will need the following fonts installed:
* Gentium
* Linux Biolinum
* Noto Serif CJK (defaults to simplified Chinese)

## Usage

Place `\include sagely` at the top of your source file.
